# 只读行为审查

审查对象为 `scripts/check_environment.sh`；测试与发布工具另有写入临时夹具和 Git 元数据的职责，不属于环境检查脚本。

## 外部命令逐项审查

- `/usr/bin/uname -s`、`-m`：读取操作系统名称和当前进程架构。
- `/usr/bin/sw_vers -productVersion`：读取 macOS 版本。
- `/usr/libexec/PlistBuddy -c 'Print :…'`：只读三个固定字段：Bundle ID、显示版本、Build。没有 Save、Set、Add、Delete 等操作。
- `/usr/bin/codesign --display --verbose=4`：只显示签名元数据；原始输出仅保留在内存中，按固定模式归纳。
- `/usr/bin/codesign --verify --deep --strict --all-architectures`：只验证应用和已知嵌套组件，没有 sign、force、remove-signature、extract-certificates 或文件输出参数。
- Bash 内建命令仅做参数解析、路径与文件属性判断、字符串处理和标准输出；输出重定向仅到 `/dev/null`，没有对应用、数据或配置文件的写入。

命令模式依据开发机自带的 `codesign(1)` 手册和 `PlistBuddy -h` 检查。查询和验证不会改变被验证代码的签名；系统本身的后台缓存、审计和文件访问时间不在零写入保证范围内。

## 数据与路径边界

默认目标是 `/Applications/WeChat.app`，可用 `--app` 指定可信的绝对 `.app` 路径。拒绝控制字符、路径穿越以及目标、父路径、Info.plist、已知组件路径中的符号链接。先检查 Bundle ID，再检查签名；不根据不可信版本号拼接命令。

脚本只显式读取指定包内的 Info.plist，并调用系统签名验证器读取包和嵌套代码。不枚举家目录、聊天容器、登录态、日志、钥匙串或其他修复项目。`codesign` 自己解析的包内链接与资源需要信任输入应用包，因此此脚本不作为恶意包分析工具。

无 sudo、应用启动、进程终止、网络客户端、补丁、复制、删除、重签名、权限重置、数据库写入或系统安全设置命令。绝对系统工具路径避免 PATH 中同名可执行文件被调用。

## 验证证据与限度

自动化测试验证固定命令参数、输出过滤、错误退出码、路径处理与组件缺失。真实系统工具仅在临时合成的未签名应用包上执行，前后比较文件内容 SHA-256、类型、权限、属主、大小、修改时间、状态变更时间和扩展属性；不比较读取可改变的访问时间。

真实系统集成还注入同名伪工具和带 shell 元字符的应用路径，确认没有调用伪工具或执行路径文本。本次不运行实际微信，不读取聊天数据，也不检查或改变系统安全设置。此验证证明所测试路径中的行为，并结合静态代码审查支持只读结论；它不是对所有 macOS 版本或恶意输入的形式化证明。
